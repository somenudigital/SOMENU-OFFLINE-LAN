# SOMENU Software - User Guide

Welcome to the **SOMENU Offline Point of Sale (POS) System**. This guide provides an overview of how the software operates and how to ensure your staff devices connect seamlessly to the system.

---

## What is SOMENU Software?

SOMENU is a robust, reliable, and entirely offline POS system designed specifically for restaurants and cafes. It empowers you to manage your daily operations, process orders, and handle billing without relying on an active internet connection.

Because the system operates offline, it ensures maximum data privacy and eliminates any downtime caused by internet outages. 

## How It Works: The Local Area Network (LAN)

Unlike cloud-based systems that store data on the internet, SOMENU operates on a **Local Area Network (LAN)**. 

### 1. The Main Server (Admin PC)
Your main computer (where the SOMENU desktop software is installed) acts as the **Server**. All of your restaurant's data—including menus, tables, orders, and sales reports—is securely stored directly on this computer.

### 2. The Network Router
Your Main Server must be connected to a Wi-Fi router. This router acts as the central hub that broadcasts the network to your establishment. **Note:** The router does not need to provide internet access; it simply provides a local Wi-Fi signal.

### 3. Staff Mobile Devices (APK)
Your staff members use Android devices installed with the **SOMENU Staff Application (APK)**. For the staff app to communicate with the Main Server and send orders to the kitchen or billing desk, it must be connected to the **same Wi-Fi router network** as the Main Server.

---

## Important Networking Rules

To ensure uninterrupted service and smooth order syncing, please adhere to the following network requirements:

- **Same Wi-Fi Network is Mandatory**: Every staff mobile device running the SOMENU app **MUST** be connected to the exact same Wi-Fi router that the Main Server PC is connected to. 
- **No Mobile Data**: The system does not use 4G/5G mobile data. If a staff member disconnects from the restaurant's Wi-Fi and switches to their mobile data, their application will immediately lose connection to the POS.
- **Dedicated Router Recommended**: For the best performance, especially in larger restaurants, we highly recommend using a dedicated, high-quality Wi-Fi router solely for your POS network to prevent congestion from guest Wi-Fi.

## Troubleshooting Connectivity Issues

If a staff member's device cannot connect to the system or orders are not going through:

1. **Check the Wi-Fi**: Verify that the staff device is connected to the correct Wi-Fi network (the one associated with the Main Server).
2. **Check the Server PC**: Ensure the Main Server PC is turned on, the SOMENU software is open and running, and the PC is connected to the router.
3. **Turn Off Mobile Data**: Sometimes mobile devices try to prioritize cellular data. Turn off Mobile Data on the staff devices to force them to use the local Wi-Fi network.
4. **Restart Router**: If multiple devices are failing to connect, try restarting your Wi-Fi router.
